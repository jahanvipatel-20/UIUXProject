# TaskFlow – Smart Productivity Platform

## About
TaskFlow is a productivity platform designed to help students and professionals manage their daily tasks and improve productivity.

## Features
- Task Management
- Team Collaboration
- Progress Tracking

## Tools Used
- Figma
- Auto Layout
- Components
- Typography and Color Styles

## Target Audience
College students, freelancers and working professionals.
